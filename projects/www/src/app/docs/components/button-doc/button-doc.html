Button

Use bootstrapng's bngButton directive for actions in forms, dialogs, and more with support for multiple themes, styles, and sizes.

Base class

The .btn class sets up basic padding and content alignment. Apply bngButton on top of it to opt into theme and style variants. 

<button class="btn">Base class</button>

Variants

Combine a theme with a style using the theme and variant inputs.

@for (theme of themes; track theme) { @for (style of styles; track style) { } } 
<button bngButton theme="primary" variant="solid">Primary</button>
<button bngButton theme="primary" variant="outline">Primary</button>
<button bngButton theme="primary" variant="subtle">Primary</button>

Text buttons

Set variant="text" to create a button that looks like a link.

@for (theme of themes; track theme) { } 
<button bngButton variant="text" theme="primary">Primary</button>

Sizes

Use the size input for extra small, small, default, or large buttons.

<button bngButton theme="primary" size="xs">Extra small</button>
<button bngButton theme="primary" size="small">Small</button>
<button bngButton theme="primary">Default</button>
<button bngButton theme="primary" size="large">Large</button>

Icon buttons

Set size="icon" for square buttons that contain only an icon. Always include an aria-label. 

<button bngButton theme="primary" size="icon" aria-label="Confirm">
  <i class="bi bi-check2"></i>
</button>

Disabled state

Add the disabled attribute to make a button inactive.

<button bngButton theme="primary" disabled>Primary button</button>

Block buttons

Use the .d-grid utility to create full-width "block buttons".

<div class="d-grid gap-2">
  <button bngButton theme="primary">Button</button>
  <button bngButton theme="primary">Button</button>
</div>

Toggle buttons

Apply bngButton to a <label> with a .btn-check class and a nested checkbox to create a button-like toggle. 

<label class="btn-check" bngButton theme="primary">
  <input type="checkbox" autocomplete="off" />
  Toggle
</label>
